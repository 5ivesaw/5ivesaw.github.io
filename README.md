# 5ivesaw.github.io

Official personal portal, in-browser creative tools, interactive engineering demos, and background music.

🌐 **Live Website:** [https://5ivesaw.github.io](https://5ivesaw.github.io)

### In-Browser Local Tools
- **Image Studio:** Batch convert, crop, resize, rotate, and filter images.
- **Audio Cutter:** Waveform trimming, fades, normalization, and WAV export.
- **Video Cutter:** In-browser trimming, muting, and audio extraction.
- **Dev Toolkit:** JSON formatting, Base64, URL encoding, hashes, and UUIDs.

### Flagship Demos
- **A* Pathfinder:** Humanized Catmull-Rom spline pathfinding on a 2D grid (*fivesawUtils*).
- **ASCII Media Player:** Real-time audio spectrum ASCII visualizer (*Ascii-Media-Player*).
- **Cursed Text Renderer:** Webcam & silhouette cursed text renderer (*a-apple-that-is-bad*).
